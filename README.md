ASS SAUVEGARDE DES SITES DE LA

Offline Flutter Android app for appointment booking, task management, payroll report notes, and asset tracking.

The app stores records on the device with local app storage. It does not require an account, Android runtime permissions, external APIs, analytics, advertising SDKs, or cloud sync.

Project contents:
- `lib/` contains the Android app source.
- `android/` contains the Android project and release signing setup.
- `web/` contains a standalone static website.
- `docs/` contains Play Store text, data safety CSV, provided graphics, and automated phone screenshots.
